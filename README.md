# Cohort Analysis & Unit Economics Engine (Retail / E-Commerce)

Аналитический движок на Python и SQLite для склейки профилей клиентов, расчета когортного анализа (Retention/Churn), многоуровневой юнит-экономики (Базовый LTV, Прямой LTV 1/2, Чистый LTV, LTV/CAC), RFM-сегментации, генерации автономных HTML-дашбордов и локального веб-сервера.

Разработано как демонстрация инженерного подхода к аналитике в екоме и интеграциях (связка 1С, RetailCRM, Mindbox, веб-витрин и касс).

---

## Ключевые возможности

1. **Идентификация и склейка профилей (Identity Resolution):**
   - Графовая дедупликация (Union-Find с итеративным поиском и сжатием путей) по составному ключу (`client_id`, `phone`, `email`).
   - Изоляция чеков без контактов (гостевые заказы на кассе не склеиваются между собой).
   - Защита от переполнения стека (`RecursionError`) на цепочках из тысяч чеков.

2. **Двойной расчетный движок со строгим паритетом (Pandas + SQLite):**
   - Расчет матриц удержания (клиенты и выручка) на чистом Pandas и через SQL Window Functions в SQLite.
   - Поэлементная сверка матриц с допуском `rtol=0.0, atol=0.01`.

3. **Многоуровневая модель юнит-экономики (Урок 7 курса):**
   - **Базовый LTV:** Выручка на одного привлеченного клиента ($AOV \times Frequency \times Lifetime$ и $\sum Выручка / M_0$).
   - **Прямой LTV 1 (Валовая прибыль):** Выручка минус себестоимость проданных товаров (COGS по начислению).
   - **Прямой LTV 2 (Вкладная маржа / Contribution Margin):** Валовая прибыль минус доставка и эквайринг.
   - **Чистый LTV:** Прибыль после вычета стоимости привлечения (CAC).
   - **LTV / CAC:** $\text{Прямой LTV 2} / \text{CAC}$ (норматив $\ge 3.0x$).

4. **Аудит полноты данных и режим Partial:**
   - Автоматическое определение доступности `cogs`, `acquisition_cost`, `delivery_cost`.
   - В режиме `partial` (выгрузки без себестоимости и маркетинга) не рассчитывает ложные статусы убыточности (`UNPROFITABLE`), а честно выводит «не рассчитан» с рекомендациями по обогащению.

5. **Автономный HTML-дашборд (дизайн Mindbox):**
   - 100% самодостаточный HTML-файл (без внешних CDN-ссылок, работает без интернета).
   - Тепловая карта удержания (Heatmap M0–M8) с прочерками `—` для ненаступивших периодов.
   - Встроенные SVG-графики (кривая удержания, выручка по когортам, кольцевая диаграмма RFM).
   - Каскадный водопад маржинальности и блок детекции аномалий (отрицательного отвала).

6. **Локальный веб-интерфейс (`web/app.py`):**
   - Запуск на `127.0.0.1:5000`.
   - Drag-and-Drop загрузка `.csv` и `.xlsx` файлов.
   - Валидация колонок до старта с понятными сообщениями об ошибках.
   - Мгновенный просмотр дашборда и экспорт в HTML.

## Структура проекта

```
cohort-unit-economics/
├── data/
│   ├── sample_orders.csv          # Синтетический датасет (3 300+ заказов)
│   └── course/                    # 14 эталонных таблиц курса Практикума
├── src/
│   ├── generate.py                # Генератор синтетики с 2 брендами и склейкой
│   ├── prepare.py                 # Очистка, безопасная склейка профилей, парсинг дат
│   ├── cohorts.py                 # Когортный анализ на Python/Pandas
│   ├── cohorts_sql.py             # Когортный анализ на SQLite (Window Functions)
│   ├── behavior.py                # Churn, Retention, AOV, Lifetime, доступность когорт
│   ├── costs.py                   # Себестоимость (COGS), переменные расходы, CAC
│   ├── model.py                   # Модель юнит-экономики (LTV 1/2, Net LTV, LTV/CAC)
│   ├── rfm.py                     # RFM-сегментация клиентской базы
│   ├── report.py                  # Генератор управленческого Markdown-отчета v2
│   └── report_html.py             # Генератор автономного HTML-дашборда (Mindbox UI)
├── web/
│   └── app.py                     # Локальный веб-сервер на Flask (Drag-and-Drop)
├── tests/
│   ├── test_pipeline.py           # 15 тестов пайплайна, SQL-паритета и HTML
│   └── test_web_app.py            # 4 теста веб-интерфейса и валидации
├── output/                        # Сгенерированные отчеты (.md, .html)
├── main.py                        # Точка входа CLI
└── requirements.txt               # Зависимости проекта
```

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск локального веб-интерфейса

```bash
python web/app.py
```
Откройте в браузере: `http://127.0.0.1:5000` и перетащите любой CSV/XLSX файл.

### 3. Запуск через консоль (CLI)

```bash
# Генерация синтетики и отчетов (Markdown + автономный HTML)
python main.py --html

# Расчет через SQLite движок на реальных данных курса с открытием в браузере
python main.py --sql --input data/course/sheet_02_15phCO86.csv --html --open
```

### 4. Запуск тестов

```bash
python -m unittest discover tests
```
*19 тестов проверяют склейку, паритет SQL/Pandas, эталон Урока 3, формулы LTV, автономность HTML и веб-сервер.*
